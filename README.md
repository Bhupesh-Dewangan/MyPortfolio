# 🚀 3D Developer Portfolio

A modern, animated 3D developer portfolio built with React, Three.js, TailwindCSS, and motion effects — designed to help developers stand out and showcase their skills in an interactive, creative way.

## ✨ Features

- 🔥 3D visuals powered by React Three Fiber and Drei

- ⚡ Smooth transitions & scroll animations using Framer Motion

- 🎨 Clean and responsive UI built with TailwindCSS

- 💌 Working contact form using EmailJS

- 🧱 UI enhancements with Aceternity UI and Magic UI

- 🚀 Lightning-fast setup using Vite

## 🛠 Tech Stack
| Tech                  | Description                    |
| --------------------- | ------------------------------ |
| **React**             | Frontend JavaScript library    |
| **Vite**              | Fast bundler & dev environment |
| **TailwindCSS**       | Utility-first CSS framework    |
| **React Three Fiber** | Three.js in React              |
| **Drei**              | Helpers for R3F                |
| **Framer Motion**     | Animation library              |
| **EmailJS**           | Contact form email service     |
| **Aceternity UI**     | UI components                  |
| **Magic UI**          | Prebuilt design elements       |

## 📁 Project Structure

├── public/

## 🚀 Getting Started
```bash
# Clone the Repository
git clone https://github.com/Bhupesh-Dewangan/MyPortfolio
cd MyPortfolio

# Install Dependencies
npm install

# Run Development Server
npm run dev

```
App runs at: http://localhost:5173
